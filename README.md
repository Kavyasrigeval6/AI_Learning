**FASTAPI APPLICATION**
Overview: REST API is built using Python and FastAPI to perform CRUD operations on user records.

Technologies  used:
> Python
> FastAPI
> Pydantic
> Pytest
> HTTP Methods

Features:
> Add the user(POST Method)
> Retrieve the user(GET Method)
> Update the user(PUT Method)
> Delete the user(Delete Method)

Testing:
Pytest and FastAPI Testclients are used to test all the endpoint.
